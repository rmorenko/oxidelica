# Идеи и дорожная карта

Собрано из обсуждений Романа и fable, август 2026. Это документ идей, а
не обещаний: очередь текущих работ определяет `refusals.sh`, а не этот
файл. Здесь — то, что лежит за горизонтом текущей очереди, с честной
ценой и взаимными связями.

Счёт на момент записи: 639/1043 моделей flatten, 323 run (неделей
раньше — 472/131).

## Магистраль (решения, а не идеи)

1. **Полная совместимость с MSL** — текущая работа. Потолок: ~1043
   flatten, ~912 run. Побочный закон, проверенный трижды: расширение
   покрытия (модели, среды, машины) — систематический фаззер латентных
   багов; каждая новая семья моделей проверяет всё построенное раньше.
2. **Все фичи языка.**
3. **Редактор**: LSP-сервер (одна реализация — все редакторы:
   автодополнение, подсветка ошибок, hover из `why`), диаграммная
   канва (oxidelica-ide, Bevy). Сюда же вернётся вопрос декларативного
   ядра: редактору нужны инкрементальность и error-tolerant парсер —
   ровно записанные триггеры перестройки флаттенера.
   - Дешёвая привычка уже сейчас: новые узлы AST заводить со спанами
     (позициями) — избавляет редакторную фазу от сквозного ретрофита.

Рефакторинг — по трению, не по расписанию (правило в AGENTS.md).

## Задачи-передышки

Маленькие, самостоятельные, с немедленной пользой. Брать между
тяжёлыми барьерами.

- **`oxidelica sweep`** — `sweep model.mo --param R=1..100 --jobs N`:
  свипы параметров, Монте-Карло, чувствительность, калибровка. Тот же
  движок, N процессов, ансамбль CSV. Двойная отдача: практика сейчас +
  фабрика обучающих данных для ML-суррогатов потом.
- **REPL** — тёплая сессия с загруженным реестром: `flatten X`,
  `why X v`, `simulate X` без перечитывания MSL; интерактивный вызов
  функций библиотек через готовый const-eval
  (`Medium.density_pTX(1e5, 300)` → число); инкрементальная сборка
  модели с живым счётом «уравнений M, неизвестных N». Стратегически —
  эмбрион LSP: та же сессия, другой протокол.
- **Сущность проекта** — многофайловый проект пользователя (раскладка
  MLS 13.4 уже читается): манифест + `uses()`-аннотации как источник
  зависимостей, разрешение имён «корень проекта → библиотеки»,
  команды `new` / `check` / `simulate По.Имени.Класса`. Проект =
  будущий LSP-workspace. Зависимости по именам — клиент поверх индекса
  пакетов OpenModelica (публичный JSON; свой реестр не строить), с
  качеством уровня `cargo add`: версии, локфайл, громкие конфликты.

## Морозилка (витрины и ниши)

- **WASM / браузер** — доказано работающим: весь workspace без внешних
  зависимостей, `cargo build --target wasm32-wasip1` собирается без
  правок (2.7 МБ), симуляция в WasmEdge проверена (dopri45, семь
  верных знаков против e^-1). До браузера один шаг:
  wasm32-unknown-unknown + JS-обёртка (модель строкой внутрь, CSV
  строкой наружу). Отложено до конца магистрали.
- **Show HN / r/rust** — план на «пару задротов»: пост с числами и
  открытой кухней (агентная разработка, храповики, документ
  консультаций), README с гифкой и одной командой магии, бинарники в
  Releases, good-first-issues из реальной очереди барьеров. This Week
  in Rust — подача самостоятельная.
- **Modelica for kids** — детская шкурка поверх диаграммного
  редактора: курируемая библиотека компонентов (батарейка, лампочка,
  пружинка, бак), анимация вместо графиков (лампочка светится, бак
  наполняется — Bevy), отказы детским языком («лампочке не хватает
  второго провода»), кнопка «покажи математику», уровни как
  ScratchJr → Scratch. Ниша пуста: Scratch — не физика, PhET — чужие
  готовые симуляции, Algodoo — только механика. Продукт = 10% движка
  и 90% методики/контента — трезво оценивать.
- **Low-code** — два зерна поверх той же базы: **конфигураторы**
  (форма «мощность/контуры/насос» → параметризованный шаблон-проект;
  вертикаль для проектировщиков, не моделистов; открытая ниша Modelon)
  и **LLM-ассистент в редакторе** (промпт → модель; отказы компилятора
  как обратная связь; вся история jcode — работающее доказательство,
  что петля «LLM пишет Modelica + честные отказы» сходится).
- **FMU-экспорт** — валюта совместимости индустрии: компилятор,
  умеющий выплюнуть FMU, втыкается в любой чужой тулчейн, и неполнота
  покрытия перестаёт быть приговором.
- **Генерация отчётов и документации** — три слоя. (1) `oxidelica
doc`: сайт документации из `Documentation`-аннотаций классов (дух
  rustdoc); тот же парсинг аннотаций кормит hover в LSP — строится
  один раз. (2) `oxidelica report`: отчёт о симуляции (HTML/docx —
  описание, параметры, графики inline-SVG без JS-зависимостей) —
  инженерные протоколы расчётов одной командой. (3) Дальний конец:
  каркас статьи из воспроизводимого эксперимента (модель + sweep +
  графики), повествование — LLM-слоем.

## GPU и кластеры

- **Не делать**: GPU внутри одной типичной модели — события рвут
  SIMD, разреженная LU последовательна, системы малы.
- **Делать, когда придёт время**: ансамбли — «один экземпляр модели —
  один поток», явные интеграторы; кодоген WGSL из плана вычислений
  sim (wgpu). WebGPU = те же ядра в браузере: «10^4 вариантов модели
  на видеокарте во вкладке» — нет ни у кого.
- Приземлённое: шардирование стены библиотеки по CI-раннерам (48 мин →
  минуты), когда станет узким местом.

## Нейросети и модели

- **Суррогаты**: sweep генерирует данные → обучение снаружи (PyTorch).
  Бесплатное следствие sweep-команды.
- **Гибридные модели** (аналог NeuralFMU): инференс малых сетей чистой
  Modelica — Dense = матумножение + tanh, веса параметрами из .mat
  (машинерия чтения файлов уже есть). Обучение — снаружи.
- **Нейрон как физика**: Ходжкин-Хаксли, спайковые цепочки — жёсткие
  ОДУ с событиями, образцовый материал для примеров (и для kids:
  «собери нейрон, подай ток, смотри спайк»).
- **Глубокая заморозка**: обучение сквозь решатель (Neural ODE,
  сопряжённые градиенты) — исследовательская весовая категория.

## Дальний космос

- **Лазерная библиотечка** — скоростные уравнения (плотности фотонов
  и носителей): честные жёсткие ОДУ, пороги и релаксационные
  осцилляции. В MSL оптики нет не потому, что нельзя, а потому, что
  носители не пришли; эта часть — можно.
- **Демо тонких плёнок** — матрицы Абелеса/Берремана: свип длины
  волны «как времени», комплексные матрицы уже по зубам компилятору.
  Витринный экспонат — мыльная плёнка: радуга пузыря как честная
  интерференция. Привет университетской биофизике автора.
- **Декларативное ядро флаттенера** — дерево инстансов → вычисление
  по зависимостям. Триггеры возврата записаны: редакторная фаза, или
  фиксы начали регрессить соседей, или остаток отказов — про порядок.
  До того — не трогать (запланированная перестройка случается
  независимо от оснований — ловушка).

## Расширение языка (обсуждение 2026-08-31)

Строго после магистрали: репутация «100% MSL» — билет, с которым
расширения слушают. Три правила: **суперсет, не форк** (любая
стандартная модель компилируется без изменений; расширения за явным
opt-in); **десугар в стандарт** (поле после дискретизации — обычные
массивы и уравнения, экспортируемые обратно в .mo; интероп и FMU не
страдают); **прототип для стандарта, не замена** (фичи MLS исторически
приходили из прототипов инструментов — synchronous, spatialDistribution;
экосистеме негде экспериментировать, маленький компилятор — площадка).
Уроки истории: PDEModelica умерла в академии; spatialDistribution выжил,
войдя оператором; Эльмквист ушёл в Modia/Dyad, порвав совместимость —
спрос подтверждён, цена разрыва тоже.

Кандидаты по убыванию: **одномерные поля** (`field` + домен + граничные
условия → метод прямых в обычную ДАУ; только 1D — трубы, стержни,
плёнки, слои; 2D/3D = меши = никогда); **неопределённость**
(`parameter Real R = normal(100, 5)` — распределения как семантика,
стыкуется со sweep); **аннотации дифференцируемости** (задел под
Neural ODE).

**Акторная архитектура** (обсуждение 2026-08-31): в ядро компилятора и
решатель одной модели — нет (детерминизм порогов; ДАУ связна, акторы =
заново изобретённая ко-симуляция; сама Modelica сознательно выбрала
синхронную композицию, не акторную). Где да: изоляция паник в мерной
трубе — сейчас (catch_unwind вокруг модели в library check/sweep:
упавшая модель — строка результата, а не смерть 40-минутного замера);
редактор — фоновая компиляция с отменой устаревших запросов (паттерн
rust-analyzer); браузер — Web Worker = актор принудительно; флоты
ко-симуляций — супервизоры/рестарты, дальний ящик вместе с кластерами.

## Идеи fable

- **Эталонные траектории** — недостающий храповик: run-порог проверяет
  «посчиталось», но не «посчиталось правильно» — тихо неверное число на
  уровне траекторий не ловится ничем (stream-тест с 340 вместо 20
  годами был зелёным). Оракул бесплатный: официальные референсные
  результаты MSL. `library check --against-reference` с допуском =
  пятый порог, самый честный. **Решение Романа: после 100% run и
  покрытия всех фич языка** — раньше сравнение шумит расхождениями от
  недостающих фич, а не от багов. До тех пор — привычка точечных
  сверок с эталоном, когда конкретное число под подозрением (как
  вышло с 340→20).
- **Диагностика как продукт**: `why --model` для целой модели (почему
  разбаланс, кандидаты), контрфактуалы. «Компилятор, который
  объясняет» против легендарного «singular system» у конкурентов.
- **Физические инварианты как оракулы**: энергобаланс из коннекторов
  (потенциал × поток) — `verify --conservation energy` ловит классы
  ошибок, для которых нет тестов ни у кого.
- **Храповик как продукт**: GitHub Action «oxidelica-check» — пороги,
  честная труба и поимённые отказы для чужих библиотек. Методология
  проекта, упакованная наружу.
- **Семантический diff моделей**: `diff A B` по уравнениям, параметрам
  и топологии — ревью моделей в команде вместо нечитаемого текстового
  диффа с аннотациями.
- **Time-travel why** — **принято Романом: отладчик нужен**. Две
  ступени: (1) журнал причин в симуляторе (события с именами отношений,
  присвоения when, раунды итерации, посадки шага) рядом с CSV +
  `why model.mo x --at 3.2` в CLI — расширение существующей `why` во
  время, можно до редактора; (2) редакторная ступень — клик на пик
  графика → маркеры событий на оси, подсветка виновного уравнения.
  UI поверх готового слоя данных.

## Метод (почему это может сработать)

Не идея, а фундамент, на котором всё выше стоит: пороги-храповики,
которые нельзя опустить; измерение парой чисел из одной честной трубы;
отказ, называющий виновника; тест, красный без фикса; трасса раньше
теории («с картой, а не с шашкой»); консультации с одним вопросом за
раз. Подробности — AGENTS.md; история — QUESTION_FOR_FABLE.md.
